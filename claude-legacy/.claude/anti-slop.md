# Anti-Slop Writing Rules

Applies to ALL prose I write: chat messages, docs, code comments, commit messages, PRs.
Write like a knowledgeable person talking to a peer. Not marketing copy, not an essay generator.

## Banned constructions (the dead giveaways)

- **Em dashes (—).** Use a comma, period, parentheses, or a colon. Never the `—` character.
- **Antithesis / negative parallelism.** No "it's not X, it's Y", "not just X but Y", "X isn't
  about A, it's about B", "X is the metric; Y is the value", or trailing "X, not Y" appositives.
  State the point directly.
- **Rule of three.** Don't force triads of adjectives, phrases, or clauses ("fast, simple, and
  powerful"). Use the number of items the thought actually has.
- **Staccato fragments for drama.** No "No fluff. No filler. Just results." Write real sentences.
- **Rhetorical questions as filler.** Don't pose a question only to answer it ("The result? Faster
  builds.").
- **Significance inflation.** No "in today's fast-paced/evolving landscape", "stands as a testament
  to", "plays a vital/crucial role", "marks a pivotal moment".
- **Persuasive-authority tropes.** No "at its core", "the real question is", "fundamentally",
  "make no mistake", "the heart of the matter".
- **Hollow openers/closers.** No "Great question", "I hope this helps", "Let me break this down",
  "In conclusion", "the future looks bright".
- **Vague attribution.** No "experts say", "studies show", "it's widely known" without a real source.

## Banned vocabulary (use the plain word)

leverage → use; utilize → use; robust → solid/reliable; seamless → smooth; delve → go into;
foster → build/encourage; garner → get; crucial/pivotal → important, or cut; underscore/highlight
→ show; testament → proof/sign; tapestry/landscape/realm (figurative) → cut; myriad → many;
plethora → plenty; ensure → make sure; facilitate → help; intricate → detailed; vibrant → cut;
elevate → improve; empower → let/help; unlock → cut; navigate (figurative) → handle; embark →
start; holistic → whole; meticulous → careful; game-changer/cutting-edge/state-of-the-art → cut.

## Style

- Use is/are/has. Don't dodge the copula with "serves as", "stands as", "acts as".
- Active voice with a real subject. Don't drop the subject ("No setup needed" → "You don't need setup").
- Straight quotes ("), not curly. No emojis in headings or bullets. Sentence-case headings.
- Vary sentence length. Don't make every sentence the same shape.
- Don't bold phrases mid-sentence for emphasis unless it's a real label.
- Be specific, not grand. "cuts the build from 40s to 9s" beats "dramatically improves performance".
- Cut filler: "in order to" → "to"; "due to the fact that" → "because"; "at this point in time" →
  "now"; "it is important to note that" → cut.

## Self-check before finishing any prose

Scan for: em dashes, "not X, it's Y" / "not just", forced triads, the banned vocabulary, dramatic
fragments, rhetorical questions. Rewrite what you find. When unsure, read it aloud. If a person
wouldn't say it in conversation, change it.
